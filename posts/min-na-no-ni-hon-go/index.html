前言#

emmmmm前段时间去日本玩了趟，开始对日语感兴趣了，目前学习的时候感觉东西都能理解，但是怕自己总结的东西过了脑子就忘，所以做一个电子笔记。

初级上#

第一课#

  • あなた：称呼“你”。日语中很少使用第二人称代词，语境明确时更是如此。初次见面用可能冒犯。也有“亲爱的”的意思。
  • ～ちゃん：昵称结尾，常见于动画、口语中，相当于“~酱”。
  • 句式：
    名词1 は 名词2 です
    其中は作助词读作 わ (wa)，不是 は (ha)。

第二课#

  • お土産：礼物，地方特产，当地纪念品。
  • 「お」可以接续名词，表示郑重、敬语语气。

第三课#

  • お手洗い（御手洗）：
    • お手洗い指洗手间，常用。
    • 御手洗通常不指厕所，多用作姓氏。
  • 〜をください：请给我～，其中を作助词，念作o。
  • エレベーター：电梯（elevator）
    エスカレーター：自动扶梯（escalator）
  • 「お」放在听话人或第三者有关的事物前表示敬意。例：お国はどちらですか？

第四课#

  • ～時的读音特殊：
    • 四時 よじ
    • 七時 しちじ
    • 九時 くじ
  • ～分读音规则：
    • 2、5、7、9结尾的分读ふん，其余读ぷん。
    • 例：一分 いっぷん、六分 ろっぷん、八分 はっぷん、十分 じゅっぷん
  • 日语动词分三类：
    1. 动I：结尾是う行假名，变礼貌形时假名变い行，加ます。
      例：休む → 休み → 休みます
    2. 动II：以る结尾，前一假名为え行或い行，去る加ます。
      例：起きる → 起き → 起きます
    3. 动III：无规则，需记忆。
  • 时间名词后加に表示动作发生时间。
    例：6時に起きます。
  • ～から～まで 表示动作起止时间或地点，两词可单独使用。
  • ます、ません、ました、ませんでした：动词礼貌体的肯定、否定、过去肯定、过去否定。
  • 词尾ます说明前面是动词。

第五课#

  • 周、月的“上中下”用词：
    • 先週・今週・来週
    • 先月・今月・来月
  • 年的“上中下”：
    • 去年（きょねん）・今年（ことし）・来年（らいねん）
  • 说具体月份用がつ读法，不用げつ。特殊读音：
    • 四月 しがつ
    • 七月 しちがつ
    • 九月 くがつ
  • 日期读音（1号-10号特殊）：
    • 四日 よっか
    • 八日 ようか
    • 十四日 じゅうよっか
    • 二十日 はつか
    • 二十四日 にじゅうよっか
  • 何月（なんがつ）、何日（なんにち）分别用于询问月份、日期。
  • 模糊询问时间用いつ，与表示“几点”的なんじ区分。
    • 例：いつ広島へ行きますか？三月二十五日に行きます。
    • 时间点加助词に，时间段作为副词不用助词。
  • 列车种类：普通（ふつう）、急行（きゅうこう）、特急（とっきゅう）、快速（かいそく）、準急（じゅんきゅう）。
    • 停靠站点多到少，速度快到慢：特急 > 急行 > 快速 > 準急 > 普通
  • 快速（かいそく）和家族（かぞく）发音容易混淆。
  • 移动方向助词へ用法：
    • 大阪へ行きます。
    • Tokyoへ来ました。
    • うちへ帰ります。
  • 疑问词否定表达：疑问词 + も + 动词否定形
    • 例：Q：どこへ行きますか？ A：何(へ)も行きません。
  • 助词で表示手段、方法、工具，接交通工具表示交通方式。
    • Q：何で大阪へ来ましたか？
    • A：バスで来ました。
  • 助词と表示与谁一起行动。
    • 私は家族と日本へ来ました。
    • 私は一人で日本へ来ました。（单独行动不加と）
  • 助词よ放句尾，表示自己的判断、意见，类似“～哟”。

第六课#

  • 他动词宾语用助词を。他动词为“对某人/物施加动作使其变化”的动词。
  • 名词をします表示做相关事情。
    • 电话をします（打电话）
    • 宿題をします（做作业）
  • 何 读法区分：
    • なん：接た、だ、な行词时使用。
    • なに：一般用法。
  • なんで问手段、理由。手段更专用时用なにで。
  • 招呼邀请句：
    • 〜ませんか？表示邀请做某事。
    • 〜ましょう更礼貌的邀请。
  • 时间词：
    • 何時（いつ）什么时候
    • いつか 5号
    • いつも 总是

第七课#

  • 助词で用于表示手段、方法、工具：
    • 箸で食べます。 用筷子吃饭。
    • 日本語でお手紙を書きます。 用日语写信。
  • 助词に表示动作收益者/被影响者或动作目标：
    • 私は木村さんに花をあげました。 我送花给木村先生。
    • 私は木村さんに花をもらいます。 木村先生给我送花。
    • 私はカリナさんにCDを借りました。 我向卡丽娜借CD。
  • 表示来源时，可用から替代に，尤其对象为非人的银行、学校等机构时必须用から。
    • 私はカリナさんからCDを借りました。
    • 私は銀行からお金を借りました。 我从银行借钱。
  • 表示动作完成与否：
    • もう 動詞 ました：已经…了
    • 例：もう荷物を送りましたか？
      • はい、送りました。
      • いいえ、まだです。
  • 语境清楚时，助词可省略。
    • コーヒー[を]もう一杯ですか？

第八课#

  • 形容词类别：い形容词（イ形）、な形容词（ナ形）。
  • 两种形容词均可直接做谓语：
    • 富士山は高いです。（イ形）
    • 桜は綺麗です。（ナ形）
  • 修饰名词时用法不同：
    • い形容词直接放前面：富士山は高い山です。
    • な形容词加な：桜は綺麗な花です。
  • 同音词区分：
    • 暑い（天气热）、熱い（物体热）
    • 对应反义词分别是寒い、冷たい
    • 价格高/高度高：高い
    • 便宜的：安い；低的：低い
  • い形容词有两种语调：
    • -2型：高语调到倒数第二假名，谓语时用。
    • 0型（平板型）：整个单词语调平，修饰名词时用。
  • い形容词以い结尾；な形容词只有词干（例如：綺麗 きれい 词干即为词尾い）。
  • 否定形式：
    • い形否定：去掉结尾い，加くないです。
      • 例：面白い→面白くないです。
    • いい的否定特殊：よくない。
    • な形否定：词干后接じゃありません。
      • 例：静かじゃありません。
  • 接续词：
    • ～が、～ 表转折，意为“但是”。
    • そして 表示并列，意为“而且”。

第九课#

  • 形容词和一部分动词的宾语用が表示
    • 私は中国料理が好きです。
    • 私は中国語がわかります。
    • 私は車があります。
  • 日语中副词一般放在动词的前面
    • お金たくさんあります。
  • 〜から、〜 から前面半句是后面句子的原因
    • 時間がありませんから、新聞を読みません。
  • 也可以用~から补充理由
    • 毎朝新聞を読みますか？
    • いいえ、時間がありませんから。
  • どうして用于询问原因，在答语的结尾要加から。
    • どうして今朝新聞を読みませんでしたか？
    • 時間がありませんでしたから。
  • 别人的妻子：奥さん（おくさん） 自己的妻子：妻（つま　１）
  • 别人的丈夫：ご主人（ごしゅじん） 自己的丈夫：夫（おっと）

第十课#

  • いる　ある分别用于表示人与物的存在，译为在、有
    • 佐藤さんがいます。 //　名詞が あります/います。
    • 佐藤さんは庭にいます。 // 名詞は場所に あります/います。
    • 庭に里さんがいます。 // 場所に名詞が　あります/います。
  • 表示方位的词如下：
    • 上　うえ
    • 下 した
    • 右 みぎ
    • 隣 となり
    • 前 まえ
    • 後ろ うしろ
    • 左 ひだり
    • 中 なか
    • 外 そと
    • 近く ちかく
    • 間 あいだ
  • 名詞　や　名詞　が　あります。中的ya表列举，有多样东西时列举两样及以上。
    • 箱の中にお手紙や写真があります。 // 箱子里有信纸和照片什么的。
  • 仅仅表示有什么物/人时用 ga，但是如果提及地点里有什么，那么仍然是地点ni人/物。

  • 数量词一般放在名词+助词后面，但表示时间长短的数量词则不受限：

    • 外国人の学生が二人(ふたり)います。 //　外国学生有两名。
    • 林檎を四つ買いました。 // 买了4个苹果。
    • 国で二ヶ月日本語を勉強しました。 // 在国内学了两个月日语。

  • 询问数量的方法

    • いくつ
      • 蜜柑がいくつ買いましたか？ //　买了几个橘子？
        • 四つです。
    • なん　询问几人、几台、几枚、几回、几时、几分、几月、几年时
      • この会社に外国人が何人いますか？ // 这家公司里有几个外国人？
      • 毎晩何時間日本語を勉強しますか？ //　每天晚上学多长时间的日语。
      • 2時間勉強します。 // 学俩小时。

  • 询问时间长短 时间段 どのくらい

    • どのくらい日本語を勉強しましたか？
      • 三年勉強しました。
    • 大阪から東京までどのくらいかかりますか？ // 大阪出发去东京要花多长时间。
      • 新幹線で３時間半かかります。 // 乘新干线三个半小时。

  • ~ぐらい 接在数量词之后表示大约的数量

    • この学校に何人いますか？
      • 千人ぐらいです。

  • 表示频度：数量词 ni ~kai 动词

    • 一月に二回映画を見ます。 // 一个月看两次电影
    • 毎日３時間日本語を勉強します。 // 一天学3小时日语。

  • 数量词/名词 da ke 表示仅止于此，不会有更多，只有这些

    • この会社に外国人3人だけいます。 // 这家公司只有3个外国人
    • 休みは日曜日だけです。 // 只有周日休息
    • このコンビニにパンだけあります。 // 这家便利店只有面包了

第十二课#

名词句、na形容词句现在/过去的肯定/否定：#

非过去（现在・未来）过去
肯定名词　あめ　です名词　あめ　でした
な形容词　しずか　ですな形容词　しずか　でした
否定名词　あめ　じゃ（では）ありません名词　あめ　じゃ（では）ありませんでした
な形容词　しずか　じゃ（では）ありませんな形容词　しずか　じゃ（では）ありませんでした

从上面可以看出，肯定句现在转为过去主要是です到でした的转变。肯定句到否定句需要加上ありません。

  • i形容词
    • 现在转为过去将形容词尾i变为かった
      • 暑いです　to　暑かったです
    • 现在转为否定，将i变为くない
      • 暑いです　to　暑くないです
    • 否定转为过去否定将くない的i转为かった
      • 熱くないです　to　熱くなかったです

此处要注意 名词和na形容词过去时态中包含でした。但是i形容词的过去形态仍然是です，只是i变成了かった。

提示
种类简体敬体
肯定（非过去）～だ～です
否定（非过去）～ではない～ではありません
肯定（过去）～だった～でした
否定（过去）～ではなかった～ではありませんでした

  • 名词1は名词2より形容词1です

    • 名词1比名词2更形容词1
      • この車はあの車より大きです。

  • 名词1と名词2どちらが好きですか

    • 询问两者中更喜欢哪一个时都用どちら询问
    • 回答：名词1/名词2 のほうが好きです。
      • 此处のほう表示xx的那一边，所以可理解为更喜欢xxx的那一边。ほう同方。
    • 今週と来週とどちらが暇ですか？
      • 来週の方が暇です。

  • 名词1の名词2 前文已经提及后，可以用名词1の来省略指代某样东西。

    • このかばんは誰のですか？
      • わたしのです。

  • 形容词の也可用于省略指代。

    • 香里奈さんのかばんはどれですか？
      • その赤くて、大きいのです。
    • 这里用到了形容词的て形表接续，用来表达又…又…。此处意为又红又大。
    • i形容词的te形为变i为くて、na形容词的te形为变na为で。
      • 静かで優しい人。 // 安静又温柔的人。

  • 名词1で　何/どこ/誰/いつ が 一番 形容词 ですか？

    • 此处de表示范围，这类问句表示在一个范围内选择一个最喜欢的。感觉类似英语中的which。
    • 何/どこ/誰/いつ做名词疑问句的主语时，用ga而不用wa。

  • 遠い(to o i)，形容词，远。

    • Fate 远坂凛 遠坂凛 to o sa ka rin

  • 第一次做某事：初めて　xxxx

    • 昨日初めてお寿司を食べました。

复习C踩坑点#

  • いくつ 主要问“具体数量 / 件数”
  • 程度、范围 → 标准是 どのぐらい

第十三课#

  • 注文　ちゅうもん

    • 意为订货。古代时确实就是意同中文的注释、记录、清单的意思；中世纪演变为请求、主张；现代意思为订货、下单。
    • ご注文は何になさいいますか？　您决定好要点什么了吗？
      • 缩写：ご注文は？

  • 牛丼　ぎゅうどん 牛肉盖饭

  • 定食 ていしょく 套餐

  • 別々に べつべつに

    • 別　べつ　另外、不同、区别
    • 別に 另外的
      • 別に理由があります。 有别的理由。
    • 別々 べつべつ 复数表强调、表示各自、一个个独立分开
      • 餐厅结账：別々にお願いします。 请分开付。
      • 打包存放：これとそれ、別々に包んでください。 这个和那个请分开包装。
      • 分居：私ダチは別々に住んでいます。

  • お腹 おなか　肚子

    • なか　中　本来是里面的意思，表礼貌前面加一个お,就是委婉的表示肚子。
      • お腹がすいた 肚子饿了。
    • 《孤独的美食家》中五郎每次说肚子饿都是说：
      • 腹が減った はらがへった。

  • 広い　ひろい 宽的

    • 发音很像的词：酷い ひどい 过分的

  • 名词が欲しいです。 想要XXX。

    • 今は何が一番欲しいですか？ 现在最想要什么？
      • 車が一番欲しいです。 最想要车。

  • 动词ます形たいです。 想要做什么。

    • 动词接ます的形态即为动词的ます形（不包括ma su本身）。
    • 动词ます形たいです。表示想要做什么
      • 大阪へ行きたいです。 想要去大阪。
      • 神戸で何を買いたいですか？ 在神户想买什么？
      • お腹が痛いですから、何も食べたくないです。 因为肚子痛所以啥也不想买。

  • 无论是欲しい还是〜たい都不能用于劝别人做某事，例如：

    • コーヒーが欲しいですか？ X
    • コーヒーを飲みたいですか？　X
    • コーヒーはいかがですか？ √
    • コーヒーを飲みませんか？ √

  • 地点+へ+动词masu形/名词+に+ki/iki/kaeriます

    • 当动词是来/行き/帰ります、此时用ni表示目的
      • 神戸へ船を見に行きます。 去神户看船。
      • 私の家へゲームをしにきます。 来我家玩游戏。
    • 动词masu形中有し的，在该语句中不带し
      • デパートへ買い物にいきます。（買い物します）

  • 时间+动作可以省略助词

    • 今日行きます。 今天去

  • 但是时间+形容词就不能省略

    • 今日は忙しいです。

  • 「今日は行きます」和「今日行きます」

    • 前者表强调是今天去，后者是普通的表示今天去

第十四课#

  • 釣ります（釣る）表示钓鱼，但是おつり表示零钱
提示

这就得追溯到日本的江户时代了。 当时流通的货币（比如金币、银币）形状和重量并不完全统一，所以商人在交易时，不是单纯地“数钱”，而是需要用**天秤（悬挂式的秤）**来“称重”。

商人把客人的钱放在天秤的一边，把货物（或等价的砝码）放在另一边。

为了让天秤两端保持平衡，这个“使之平衡”的动作在日语里叫做**「釣り合わせる（tsuriawaseru）」或「釣り合う（tsuriau）」**。

如果客人给的钱多了，天秤就不平了。为了让天秤重新“平衡”，商人必须退还一部分钱给客人。这部分用来**“找齐平衡”的钱**，就被称作了**「釣り（tsuri）」**。

后来，人们在前面加上了表示尊敬和美化的前缀「お」，就变成了今天大家熟知的 「お釣り（otsuri）」。

动词类型#

动词类别判断顺序特征与规则 (看字典形)代表词汇
第三类动词第一步只有 する (包含名词+する) 和 来る(くる)する、勉強する、来る
第二类动词第二步词尾是 る，且 る 前面的音在 i 段 或 e 段食べる、見る、起きる
第一类动词第三步① 词尾不是 る 的所有词
② 词尾是 る，但 る 前面是 a、u、o 段
③ 少数死记硬背的“特殊一类”（长得像二类）		飲む、買う (非る结尾)
作る、終わる (る前非i/e)
帰る、切る、知る (特殊词)

第三类动词

第一类动词
(五段动词)		词尾在 「う (u) 段」 上词尾变成同行的 「い (i) 段」 音
然后加上 ます		買う (u) → 買います (i-masu)
待つ (tsu) → 待ちます (chi-masu)

話す (su) → 話します (shi-masu)

  • 动词て形 + ください　表请求

    • すみません、この漢字の読み方を教えてください。
    • ポルペンで名前を書いてください。

  • 动词て形 + います　表示动作正在发生

    • ミラさんは今電話をかけています。
    • 今雨が降っていますか？
      • はい、降っています。
      • いいえ、降っていません。

  • 动词ます形 + ましょう

维度用法 A：提议 / 邀请用法 B：志愿 / 承当
中文对应“（我们）一起……吧”“（让我）来……吧”
核心逻辑双向/共同：动作由双方共同完成单向/服务：动作由说话人独自完成
动作主体说话人 + 听话人 (We)说话人自己 (I)
适用场景共同行动、达成共识（如：约饭、休息）解决对方困难、提供帮助（如：提包、开门）
典型标志词常连用 「一緒に (isshoni)」常连用 「私が (watashi ga)」
疑问形式〜ましょうか？ (我们要不要一起?)〜ましょうか？ (要不要我帮你?)
例句 1行きましょう！
(走吧！/ 我们出发吧)		（私が）行きましょう。
(我去吧。/ 比如替对方跑腿)
例句 2食べましょう。
(开动吧。/ 大家一起吃)		（私が）作りましょう。
(我来做饭吧。/ 帮对方下厨)

第十五课#

  • 动词て形もいいですか？ ……可以吗？ //请求得到许可

    • ここでたばこを吸ってもいいですか？
      • ええ。吸ってもいいですよ。
      • すみません。喉がちょうど痛いですから。
      • いいえ。吸ってはいけません。禁煙ですから。

  • 动词て形はいけません。 禁止…

    • ここで吸ってはいけません。禁煙ですから。

  • 动词て形います。 除了上一课的表示正在做某事，还可以表示状态。

    • 私は結婚しています。 我结婚了。
    • カメラを持っています。 我有照相机/我拿着照相机。
    • 市役所の電話番号が知っていますか？ //知る比较特殊，否定形式不是いません。
      • いいえ、知りません。

  • 名词に动词 此处に可以表示因动词的结果而存在于某一场所

    • ここに入っていけません。 不可以坐在这。
    • ここに座ってもいいですか？ 可以坐在这吗？
    • 渋谷駅から15番のバスに乗ってください。

  • 名词1に名词2を动词 此处に表示动词的结果的场所或名词2存在的场所，即名词1

    • ここに車を止めてください。
    • ここに住所を書いってください。

第十六课#

  • 用て（で）将两个即两个以上的句子连起来 但不能用于形容相反的评价，转折需要用が。

    • 动词te de形
      • 朝ジョッギングをして、シャワーを浴びて、会社へ行きました。
      • 神戸へいて、映画を見て、お茶を飲みました。
    • i形容词 i变成くて
      • ミラーさんは若くて、元気です。
      • 昨日の天気は良くて、暑かったです。
    • な形容词 な变成で
      • ミラーさんはハンセムで、親切です。
      • 奈良は静かで、綺麗な町です。
    • 名词de
      • カリナさんはインドネシア人で、富士大学の留学生です。
      • 香里奈さんは学生で、マリアさんは主婦です。

  • 动词1て形から、动词2 表示动词2是动词1之后进行的动作，因此动词1是动词2的前提，时态根据动词2的时态定。另外，动词1から的主语用が来定。

    • お金を入れてから、バタンを押してください。
    • 昼ご飯を食べましたか？
      • この仕事が終わってから、食べていきます。

  • 名词1は名词2が形容词 表示名词1具有名词2が形容词这样的性质

    • 大阪は食べ物が美味しいです。
    • マリアさんは髪が長いです。

第十七课#

动词分类词尾特征/代表词变化规则动词原形 (辞书形)ない形 (否定形)中文意思备注说明
一类动词
(五段动词)		う词尾的「う段」假名
变为同行的「あ段」
然后加「ない」

(特例：词尾是「う」的，需变为「わ」后加「ない」)		会う (au)会わない (awanai)见面极重要：单个「う」结尾一律变「わ」
く書く (kaku)書かない (kakanai)写
ぐ泳ぐ (oyogu)泳がない (yoganai)游泳
す話す (hanasu)話さない (hanasanai)说话
つ待つ (matsu)待たない (matanai)等待
ぬ死ぬ (shinu)死なない (shinanai)死
ぶ呼ぶ (yobu)呼ばない (yobanai)呼喊
む読む (yomu)読まない (yomanai)读
る走る (hashiru)走らない (hashiranai)跑走る外形像一段，实际是五段动词（例外）
二类动词
(一段动词)		い段 + る直接去掉词尾的「る」
然后加上「ない」		見る (miru)見ない (minai)看倒数第二个假名在 い 段
起きる (okiru)起きない (okinai)起床
え段 + る食べる (taberu)食べない (tabenai)吃倒数第二个假名在 え 段
教える (oshieru)教えない (oshienai)教
三类动词
(不规则动词)		サ变特殊变形，需死记する (suru)しない (shinai)做所有的“名词+する”同此变化（如：勉強しない）
カ变来る (kuru)来ない (konai)来读音变化大：原形 kuru 变为否定 konai
特殊动词ある独立特例，无规律ある (aru)ない (nai)有、在日语中没有“あらない”这种形式，直接用「ない」

  • 动词ない形ないでください 请不要……

    • 元気ですから、心配しないでください。
    • ここで写真を撮らないでください。

  • 动词ない形なければなりません 必须……

    • 薬を飲まなければなりません。

  • 动词ない形なくてもいいです 不……也可以

    • 明日来なくてもいいです。

  • 宾语主题化。名词を动词 可以把を改成は,然后将名词放在句首来把宾语主题化。

    • ここに車を止めないでください。 这里不能停车。
      • 車はここに止めないでください。 车不能停在这里。
    • 会社の食堂で昼ご飯をたべます。
      • 昼ご飯は会社の食堂で食べます。

  • 名词までに动词。 表示动作截止的期限。

    • 会議は5時までに終わります。
    • 土曜日までに本を返さなければなります。
