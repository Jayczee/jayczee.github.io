最近一直在研究自建或者和别人拼车节点，学习到了很多概念。

## 落地机
**懂的都懂：** 所谓落地，也就是链路的最终站。落地鸡**不在乎线路，但很在乎IP质量**。

- **原生 IP 、广播 IP：** 如果想要看 Netflix、Disney+ 或者 用AI，必须得是当地的“原生 IP”。如果 IP 是机房广播过去的，大概率会被这些服务商拉黑。

- **家宽/住宅 IP：** 顾名思义，这些IP的质量最高，会让服务器觉得你就是一个普通的当地住户。

## 线路

- **163 骨干网 (AS4134)：** 免费国道，平时能跑，晚高峰就堵，丢包率就上来了。
- **精品线路 (CN2 GIA / AS9929 / CMIN2)：** 买线路鸡的首选，好的线路机三网优化。不是三网优化就需要看自己的运营商进行选择。
  - **CN2 GIA (电信)** 
  - **AS9929 (联通)** 
- **IPLC / IEPL：** 不经过防火墙，物理级别的点对点连接。只有贵这一个缺点，但最近动荡的比较多。

## 线路机 / 中转机

- **为什么要线路鸡** 因为有些落地机虽然 IP 漂亮，但它到你家的线路实在太烂。这时候我们找一台“连接你很快”且“连接落地机也很快”的机器做跳板。
- **常见选择** 常见的配置是找一台香港或者日本的机器做中转。国内连香港延迟低，香港走精品线路去其他国家落地鸡也飞快，可以大幅度降低延迟。

## 谷歌送中

由于你的真实设备开着定位，或由于近期活动等巴拉巴拉原因，谷歌将你的IP地址标记为中国地区。
表现如下：

- 谷歌随便搜索什么，页面最下方定位处于中国，域名跳转到google.com.hk。
- gemini不可用
- 油管premium不可用。
- 等等

唯一好处是油管没广告。

这个没招，只能避免，关闭网页定位权限，chrome下载虚拟定位插件，长期定位在与节点相同的位置。

可以试试*报告IP问题*，谷歌直接搜索，提交节点的IP和IP所在地区，据网友反馈最快也要一两周。
