## 初级上

### 第一课
- あなた：称呼“你”。日语中很少使用第二人称代词，语境明确时更是如此。初次见面用可能冒犯。也有“亲爱的”的意思。
- ～ちゃん：昵称结尾，常见于动画、口语中，相当于“~酱”。
- 句式：  
  名词1 は 名词2 です  
  其中`は`作助词读作 `わ (wa)`，不是 `は (ha)`。

---

### 第二课
- お土産：礼物，地方特产，当地纪念品。
- 「お」可以接续名词，表示郑重、敬语语气。

---

### 第三课
- お手洗い（御手洗）：  
  - お手洗い指洗手间，常用。  
  - 御手洗通常不指厕所，多用作姓氏。
- 〜をください：请给我～，其中`を`作助词，念作`o`。
- エレベーター：电梯（elevator）  
  エスカレーター：自动扶梯（escalator）
- 「お」放在听话人或第三者有关的事物前表示敬意。例：お国はどちらですか？

---

### 第四课
- ～時的读音特殊：  
  - 四時 よじ  
  - 七時 しちじ  
  - 九時 くじ
- ～分读音规则：  
  - 2、5、7、9结尾的分读`ふん`，其余读`ぷん`。  
  - 例：一分 いっぷん、六分 ろっぷん、八分 はっぷん、十分 じゅっぷん
- 日语动词分三类：  
  1. 动I：结尾是う行假名，变礼貌形时假名变い行，加ます。  
     例：休む → 休み → 休みます  
  2. 动II：以る结尾，前一假名为え行或い行，去る加ます。  
     例：起きる → 起き → 起きます  
  3. 动III：无规则，需记忆。  
- 时间名词后加`に`表示动作发生时间。  
  例：6時に起きます。  
- ～から～まで 表示动作起止时间或地点，两词可单独使用。  
- ます、ません、ました、ませんでした：动词礼貌体的肯定、否定、过去肯定、过去否定。  
- 词尾`ます`说明前面是动词。

---

### 第五课
- 周、月的“上中下”用词：  
  - 先週・今週・来週  
  - 先月・今月・来月  
- 年的“上中下”：  
  - 去年（きょねん）・今年（ことし）・来年（らいねん）  
- 说具体月份用`がつ`读法，不用`げつ`。特殊读音：  
  - 四月 しがつ  
  - 七月 しちがつ  
  - 九月 くがつ  
- 日期读音（1号-10号特殊）：  
  - 四日 よっか  
  - 八日 ようか  
  - 十四日 じゅうよっか  
  - 二十日 はつか  
  - 二十四日 にじゅうよっか  
- 何月（なんがつ）、何日（なんにち）分别用于询问月份、日期。  
- 模糊询问时间用`いつ`，与表示“几点”的`なんじ`区分。  
  - 例：いつ広島へ行きますか？三月二十五日に行きます。  
  - 时间点加助词に，时间段作为副词不用助词。  
- 列车种类：普通（ふつう）、急行（きゅうこう）、特急（とっきゅう）、快速（かいそく）、準急（じゅんきゅう）。  
  - 停靠站点多到少，速度快到慢：特急 > 急行 > 快速 > 準急 > 普通  
- 快速（かいそく）和家族（かぞく）发音容易混淆。  
- 移动方向助词`へ`用法：  
  - 大阪へ行きます。  
  - Tokyoへ来ました。  
  - うちへ帰ります。  
- 疑问词否定表达：疑问词 + も + 动词否定形  
  - 例：Q：どこへ行きますか？ A：何(へ)も行きません。  
- 助词`で`表示手段、方法、工具，接交通工具表示交通方式。  
  - Q：何で大阪へ来ましたか？  
  - A：バスで来ました。  
- 助词`と`表示与谁一起行动。  
  - 私は家族と日本へ来ました。  
  - 私は一人で日本へ来ました。（单独行动不加`と`）  
- 助词`よ`放句尾，表示自己的判断、意见，类似“～哟”。

---

### 第六课
- 他动词宾语用助词`を`。他动词为“对某人/物施加动作使其变化”的动词。  
- `名词をします`表示做相关事情。  
  - 电话をします（打电话）  
  - 宿題をします（做作业）  
- 何 读法区分：  
  - `なん`：接た、だ、な行词时使用。  
  - `なに`：一般用法。  
- `なんで`问手段、理由。手段更专用时用`なにで`。  
- 招呼邀请句：  
  - 〜ませんか？表示邀请做某事。  
  - 〜ましょう更礼貌的邀请。  
- 时间词：  
  - 何時（いつ）什么时候  
  - いつか 5号  
  - いつも 总是

---

### 第七课
- 助词`で`用于表示手段、方法、工具：  
  - 箸で食べます。 用筷子吃饭。  
  - 日本語でお手紙を書きます。 用日语写信。  
- 助词`に`表示动作收益者/被影响者或动作目标：  
  - 私は木村さんに花をあげました。 我送花给木村先生。  
  - 私は木村さんに花をもらいます。 木村先生给我送花。  
  - 私はカリナさんにCDを借りました。 我向卡丽娜借CD。  
- 表示来源时，可用`から`替代`に`，尤其对象为非人的银行、学校等机构时必须用`から`。  
  - 私はカリナさんからCDを借りました。  
  - 私は銀行からお金を借りました。 我从银行借钱。  
- 表示动作完成与否：  
  - もう 動詞 ました：已经…了  
  - 例：もう荷物を送りましたか？  
    - はい、送りました。  
    - いいえ、まだです。  
- 语境清楚时，助词可省略。  
  - コーヒー[を]もう一杯ですか？

---

### 第八课
- 形容词类别：い形容词（イ形）、な形容词（ナ形）。
- 两种形容词均可直接做谓语：  
  - 富士山は高いです。（イ形）  
  - 桜は綺麗です。（ナ形）  
- 修饰名词时用法不同：  
  - い形容词直接放前面：富士山は高い山です。  
  - な形容词加`な`：桜は綺麗な花です。  
- 同音词区分：  
  - 暑い（天气热）、熱い（物体热）  
  - 对应反义词分别是寒い、冷たい  
  - 价格高/高度高：高い  
  - 便宜的：安い；低的：低い  
- い形容词有两种语调：  
  - -2型：高语调到倒数第二假名，谓语时用。  
  - 0型（平板型）：整个单词语调平，修饰名词时用。  
- い形容词以`い`结尾；な形容词只有词干（例如：綺麗 きれい 词干即为词尾`い`）。  
- 否定形式：  
  - い形否定：去掉结尾`い`，加`くないです`。  
    - 例：面白い→面白くないです。  
  - いい的否定特殊：よくない。  
  - な形否定：词干后接`じゃありません`。  
    - 例：静かじゃありません。  
- 接续词：  
  - ～が、～ 表转折，意为“但是”。  
  - そして 表示并列，意为“而且”。

---

### 第九课
- 形容词和一部分动词的宾语用`が`表示
  - 私は中国料理が好きです。
  - 私は中国語がわかります。
  - 私は車があります。
- 日语中副词一般放在动词的前面
  - お金たくさんあります。
- 〜から、〜  から前面半句是后面句子的原因
  - 時間がありませんから、新聞を読みません。
- 也可以用~から补充理由
  - 毎朝新聞を読みますか？
  - いいえ、時間がありませんから。
- `どうして`用于询问原因，在答语的结尾要加`から`。
  - どうして今朝新聞を読みませんでしたか？
  - 時間がありませんでしたから。
- 别人的妻子：奥さん（おくさん）  自己的妻子：妻（つま　１）
- 别人的丈夫：ご主人（ごしゅじん） 自己的丈夫：夫（おっと）

### 第十课
- `いる　ある`分别用于表示人与物的存在，译为在、有
  - 佐藤さんがいます。  //　名詞が あります/います。
  - 佐藤さんは庭にいます。  // 名詞は場所に あります/います。
  - 庭に里さんがいます。  // 場所に名詞が　あります/います。
- 表示方位的词如下：
  - 上　うえ
  - 下  した
  - 右  みぎ
  - 隣  となり
  - 前  まえ
  - 後ろ  うしろ
  - 左  ひだり
  - 中  なか
  - 外  そと
  - 近く  ちかく
  - 間  あいだ
- 名詞　や　名詞　が　あります。中的ya表列举，有多样东西时列举两样及以上。
  - 箱の中にお手紙や写真があります。  // 箱子里有信纸和照片什么的。
- 仅仅表示有什么物/人时用 ga，但是如果提及地点里有什么，那么仍然是地点ni人/物。

- 数量词一般放在`名词+助词`后面，但表示时间长短的数量词则不受限：
  - 外国人の学生が二人(ふたり)います。  //　外国学生有两名。
  - 林檎を四つ買いました。  //  买了4个苹果。

- 询问数量的方法
  - いくつ
    - 蜜柑がいくつ買いましたか？  //　买了几个橘子？
      - 四つです。
  - なん　询问几人、几台、几枚、几回、几时、几分、几月、几年时
    - この会社に外国人が何人いますか？  //  这家公司里有几个外国人？
    - 毎晩何時間日本語を勉強しますか？  //　每天晚上学多长时间的日语。
    - 2時間勉強します。  //  学俩小时。
- 询问时间长短 时间段 どのくらい
  - どのくらい日本語を勉強しましたか？
    - 三年勉強しました。
  - 大阪から東京までどのくらいかかりますか？  //  大阪出发去东京要花多长时间。
    - 新幹線で３時間半かかります。  //  乘新干线三个半小时。
- ~ぐらい 接在数量词之后表示大约的数量
  - この学校に何人いますか？
    - 千人ぐらいです。
- 表示频度：数量词 ni ~kai 动词
  - 一月に二回映画を見ます。  //  一个月看两次电影
  - 毎日３時間日本語を勉強します。  //    一天学3小时日语。
- 数量词/名词 da ke 表示仅止于此，不会有更多，只有这些
  - この会社に外国人3人だけいます。 //  这家公司只有3个外国人
  - 休みは日曜日だけです。  // 只有周日休息
  - このコンビニにパンだけあります。  //  这家便利店只有面包了

### 第十二课

- <span id="名词句、na形容词句现在-过去的肯定-否定" class="legacy-anchor" aria-hidden="true"></span>

名词句、na形容词句现在/过去的肯定/否定：
  - 
  |           | 非过去（现在・未来）          | 过去               |
  |------------|------------------------------|--------------------|
  | **肯定**   | 名词　あめ　です              | 名词　あめ　でした  |
  |            | な形容词　しずか　です        | な形容词　しずか　でした |
  | **否定**   | 名词　あめ　じゃ（では）ありません | 名词　あめ　じゃ（では）ありませんでした |
  |            | な形容词　しずか　じゃ（では）ありません | な形容词　しずか　じゃ（では）ありませんでした |
  |||

  从上面可以看出，肯定句现在转为过去主要是`です`到`でした`的转变。肯定句到否定句需要加上`ありません`。

- i形容词
  - 现在转为过去将形容词尾i变为`かった`
    - `暑いです`　to　`暑かったです`
  - 现在转为否定，将i变为`くない`
    - `暑いです`　to　`暑くないです`
  - 否定转为过去否定将`くない`的i转为`かった`
    - `熱くないです`　to　`熱くなかったです`

此处要注意 名词和na形容词过去时态中包含でした。但是i形容词的过去形态仍然是です，只是i变成了かった。

:::tip
| 种类 | 简体 | 敬体 |
|------|------|------|
| 肯定（非过去） | ～だ | ～です |
| 否定（非过去） | ～ではない | ～ではありません |
| 肯定（过去） | ～だった | ～でした |

- 动词ます形たいです。 想要做什么。
  - 动词接ます的形态即为动词的ます形（不包括ma su本身）。
  - 动词ます形たいです。表示想要做什么
    - 大阪へ行きたいです。  想要去大阪。
    - 神戸で何を買いたいですか？  在神户想买什么？

  - コーヒーが欲しいですか？  X
  - コーヒーを飲みたいですか？　X
  - コーヒーはいかがですか？  √
  - コーヒーを飲みませんか？  √

    - デパートへ買い物にいきます。（買い物します）

  - 今日行きます。  今天去
- 但是时间+形容词就不能省略

### 第十四课

- 釣ります（釣る）表示钓鱼，但是おつり表示零钱
:::tip
这就得追溯到日本的江户时代了。
当时流通的货币（比如金币、银币）形状和重量并不完全统一，所以商人在交易时，不是单纯地“数钱”，而是需要用**天秤（悬挂式的秤）**来“称重”。

商人把客人的钱放在天秤的一边，把货物（或等价的砝码）放在另一边。

为了让天秤两端保持平衡，这个“使之平衡”的动作在日语里叫做**「釣り合わせる（tsuriawaseru）」或「釣り合う（tsuriau）」**。

如果客人给的钱多了，天秤就不平了。为了让天秤重新“平衡”，商人必须退还一部分钱给客人。这部分用来**“找齐平衡”的钱**，就被称作了**「釣り（tsuri）」**。

后来，人们在前面加上了表示尊敬和美化的前缀「お」，就变成了今天大家熟知的 「お釣り（otsuri）」。
:::

| :--- | :--- | :--- |
| **中文对应** | **“（我们）一起……吧”** | **“（让我）来……吧”** |
| **核心逻辑** | **双向/共同**：动作由双方共同完成 | **单向/服务**：动作由说话人独自完成 |
| **动作主体** | 说话人 + 听话人 (We) | 说话人自己 (I) |
| **适用场景** | 共同行动、达成共识（如：约饭、休息） | 解决对方困难、提供帮助（如：提包、开门） |

| **例句 1** | **行きましょう！**<br>(走吧！/ 我们出发吧) | **（私が）行きましょう。**<br>(我去吧。/ 比如替对方跑腿) |
| **例句 2** | **食べましょう。**<br>(开动吧。/ 大家一起吃) | **（私が）作りましょう。**<br>(我来做饭吧。/ 帮对方下厨) |


### 第十五课

- 动词て形もいいですか？  ……可以吗？ //请求得到许可
  - ここでたばこを吸ってもいいですか？
    - ええ。吸ってもいいですよ。
    - すみません。喉がちょうど痛いですから。
    - いいえ。吸ってはいけません。禁煙ですから。

- 动词て形はいけません。  禁止....
  - ここで吸ってはいけません。禁煙ですから。

- 动词て形います。  除了上一课的表示正在做某事，还可以表示状态。
  - 私は結婚しています。  我结婚了。
  - カメラを持っています。  我有照相机/我拿着照相机。
  - 市役所の電話番号が知っていますか？ //知る比较特殊，否定形式不是いません。
    - いいえ、知りません。

- 名词に动词 此处に可以表示因动词的结果而存在于某一场所
  - ここに入っていけません。  不可以坐在这。
  - ここに座ってもいいですか？  可以坐在这吗？
  - 渋谷駅から15番のバスに乗ってください。

- 名词1に名词2を动词 此处に表示动词的结果的场所或名词2存在的场所，即名词1
  - ここに車を止めてください。
  - ここに住所を書いってください。

### 第十六课

- 用て（で）将两个即两个以上的句子连起来 但不能用于形容相反的评价，转折需要用が。
  - 动词te de形
    - 朝ジョッギングをして、シャワーを浴びて、会社へ行きました。
    - 神戸へいて、映画を見て、お茶を飲みました。
  - i形容词 i变成くて
    - ミラーさんは若くて、元気です。
    - 昨日の天気は良くて、暑かったです。
  - な形容词 な变成で
    - ミラーさんはハンセムで、親切です。
    - 奈良は静かで、綺麗な町です。
  - 名词de
    - カリナさんはインドネシア人で、富士大学の留学生です。
    - 香里奈さんは学生で、マリアさんは主婦です。

- 动词1て形から、动词2 表示动词2是动词1之后进行的动作，因此动词1是动词2的前提，时态根据动词2的时态定。另外，动词1から的主语用が来定。
  - お金を入れてから、バタンを押してください。
  - 昼ご飯を食べましたか？
    - この仕事が終わってから、食べていきます。
  
- 名词1は名词2が形容词 表示名词1具有名词2が形容词这样的性质
  - 大阪は食べ物が美味しいです。
  - マリアさんは髪が長いです。
