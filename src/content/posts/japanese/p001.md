## 1. ~だ 助动词 表判断

表达“是学生”时，**不能直接用名词作谓语**，需要加助动词`だ`表示判断。

```text
学生だ。　// 是学生。
```

> 名词不能直接作谓语，需要加`だ`表示判断。  
> `だ`作助动词后，后面只能跟句号或终助词（如：よ、ね，表示语气）。

否定形式需要将`だ`变成`で`，再加表示强调否定的副助词`は`，以及否定的辅助形容词`ない`。

```text
学生ではない。　// 不是学生
```

> 其中，`で`是`だ`的终止形，后面可以接其他成分。

疑问形式： 

```text
学生か？　// 是学生吗？
```

<span id="_2-です-助动词-表判断-礼貌" class="legacy-anchor" aria-hidden="true"></span>

## 2. ~です 助动词 表判断 + 礼貌

`です`除了表示判断外，还有对听话人表示礼貌的含义。

```text
学生です。　// 是学生（礼貌）
学生ではありません。　// 不是学生（礼貌，ない -> ありません）
学生ですか？　// 是学生吗？（礼貌）
```

<span id="_3-である-助动词-表判断-正式体" class="legacy-anchor" aria-hidden="true"></span>

## 3. ~である 助动词 表判断 正式体

只用于演讲、论文等非常正式的场合。

```text
学生である。　// （正式）是学生
学生であります。　// 更礼貌的正式体
```

---

<span id="_4-でございます-助动词-表判断-敬语" class="legacy-anchor" aria-hidden="true"></span>

## 4. ~でございます 助动词 表判断 敬语

用于店家与客人交谈，非常礼貌且郑重。

```text
毛利探偵事務所でございます。　// 这里是毛利侦探事务所
```

<span id="_5-用法总结表格" class="legacy-anchor" aria-hidden="true"></span>

## 5. 用法总结表格

| 形式       | 一般        | 礼貌          | 正式         | 正式 + 礼貌    | 郑重           |
|------------|-------------|---------------|--------------|----------------|----------------|
| 肯定句     | だ          | です          | である       | であります     | でございます  |
| 否定句     | ではない    | ではありません | /            | /              | /              |

> 后面三种一般不使用否定用法。

<span id="_6-副助词-は-格助词-が" class="legacy-anchor" aria-hidden="true"></span>

## 6. 副助词 は / 格助词 が

```text
你是谁？　　　あなたはだれですか？
我是学生。　　私は学生だ。

谁是学生？　　だれが学生ですか？
我是学生。　　私が学生だ。
```

> は 的疑问/回答主体在は后面，而 が 的主体在前面。

---

<span id="_7-副助词-も" class="legacy-anchor" aria-hidden="true"></span>

## 7. 副助词 ~も

在判断的基础上增加了“也”的意思。

```text
私も学生です。　// 我也是学生。
```
